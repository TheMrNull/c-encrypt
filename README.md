# C-ENCRYPT

C-encrypt is a simple encryption/decryption program written in C++ that uses the
XOR operator in order to flip bits and encrypt files.

The core logic is actually short and simple, the rest is just polishing "features"
that I added to improve user experience.

I take no responsibility if **YOU** encrypt something important and forget the key
to decrypt it.

More features might come in the future but I am not very sure about it so keep
your hopes low.
As the best engineers say:
> If it works don't touch it.

## Compiling

### PREREQUISITES

CMake version 3.10

To start using the following program start by cloning the repository with
`git clone https://github.com/TheMrNull/c-encrypt.git`.  
After cloning the repo use `cd c-encrypt` and use
`mkdir build && cd build`. After "cding" into the folder `build` use `CMake ..`
to create the make file and finally use `make` to build the executable and run
it with `./c-encrypt`.

AGAIN I DO NOT TAKE ANY RESPONSIBILITY IF YOU ENCRYPT THE WRONG FILE, EVEN IF IT
SHOULD WORK AS INTENDED AND DO NOT FORGET THE ENCRYPTION KEYS.
